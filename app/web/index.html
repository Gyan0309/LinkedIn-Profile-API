LinkedIn Profile API

v1

A profile URL in, the profile as structured JSON out.

The cookie header from any logged-in request. Used for this one fetch, never logged and never written to disk — the service keeps no session of its own, so it spends your account's budget rather than anyone else's.

Needs to contain li_at.

Where do I find this?
  1. Open linkedin.com in a tab where you're signed in.
  2. Press F12, go to the Network tab, reload.
  3. Click any request to www.linkedin.com.
  4. Under Request Headers, copy the whole cookie value.

Network tab, not Application. Application lists cookies one at a time; you want the entire header the browser sends. li_at alone isn't enough — LinkedIn also expects JSESSIONID, lidc and bcookie, and without them it bounces the request to a login page.

Use the browser you're signed in to. This page also sends that browser's identity with the request, because LinkedIn ties a session to the device it was created on. Pasting the cookie into a different browser makes LinkedIn think it was stolen, and it signs you out everywhere.

Any profile URL. Locale subdomains, tracking parameters and trailing paths all work.
